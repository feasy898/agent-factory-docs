## 3. grok build cli 并发配方（2026-10-19 二次实测固化）

**坑与正解（血泪）**：
- `-p/--single` 与 `--prompt-file` 都是**单轮问答**（打印即退出）——不能用于开发任务。
- 无 PTY 直接 nohup 启动 → `Error: No such device or address (os error 6)`（TUI 要 /dev/tty）。
- **正解**：位置参数传 prompt（进入交互会话初 prompt）+ `--always-approve`（自动批全部工具执行）+ `setsid script -qec`（造 PTY）+ `--max-turns 100 --no-plan`。

```bash
# anolis 上（每实例必带代理；完整脚本=/data/af-factory/launch.sh）
export PATH="$HOME/.grok/bin:$PATH"
# ⚠️ 代理两行已于 2026-10-20 作废（hk-gateway 移出 tailnet），保留仅为历史配方
# export HTTPS_PROXY=http://100.64.0.8:7890 ALL_PROXY=http://100.64.0.8:7890
cd <实例目录>   # /data/af-factory/iN，git 分支隔离
setsid script -qec "grok --always-approve --max-turns 100 --no-plan \"\$(cat 任务卡)\"" <日志路径> &
```

- 并发实测：**5 实例稳定并发**（每实例含子进程约 3 个 grok 进程；anolis 16 核 125G 内存余裕大）。实例=目录隔离（/data/af-factory/iN，各自 git 克隆+分支），共享 CARGO_TARGET_DIR=/data/af-factory/target 与 .cargo 缓存（从本机 rsync 的 1.7G registry，离线构建）。
- 工具链：anolis 无 rust——用本机 ~/.rustup+~/.cargo 整体 rsync 到 /data/af-factory/.rustup/.cargo（RUSTUP_HOME/CARGO_HOME 指过去，版本 1.99.1 与本机完全对齐）。
- 任务下发形态：任务卡=/data/af-factory/tasks/*.md（公共纪律头 common-header.txt + 具体任务），一个 grok 实例 = 一个 crate 级任务，指令里压入质量门（L0/L1 阶梯 + `cargo test -p <crate>` 绿才算完）。
- 监控：`git -C /data/af-factory/iN log`（真实产出）+ logs/*.log（TUI 转录，含转义码仅作辅助）。
- 认证：OIDC（~/.grok/auth.json，refresh_token 自动续）。**额度 2026-10-19 17:20 过期（运营者告知）**，用尽切 GLM5.3。
