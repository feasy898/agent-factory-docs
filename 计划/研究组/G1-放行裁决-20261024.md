## 二、随裁决批准的语义澄清

1. **goto:exit 语义**（草稿批最高优先裁决项）：exit = 本 route 不产生出边 + 各 exit 分支联合守卫（文档序析取）暴露给上层；循环收束由 loop.exit_when / policies.stop 承载。图级归一化与循环级终止分层，批准此读法；提案 B 勘误列入 v0.2 议题（多份草稿的两种读法之歧义就此消除）。
2. **default 必填 = E1002**（M4 对任务包文面的纠正，比 E2101 系更准确——default 是 route 构造的形状缺失）。
3. **failures[] 无 CEL 字段**（M4 纠偏：失败分类账的路由是目标引用非谓词）。
