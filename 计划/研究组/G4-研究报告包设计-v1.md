### 2.2 tool · `pkg.report.web_fetch@1`（网页/论文抓取）

- **impl_ref**：`packages/reportkit@1.0.0/tools/web_fetch.py`。已有声明参照 `pkg.crewkit.tool.fetch@1`（components.json:172-176）。
- **绑定方式**：ingest 节点（摄取）+ reader 节点（补充检索）两处 `uses.tools`/`uses.tools` 成员。
- **入参**：`{url: string (必填, http/https)}`。
- **出参**：`{ok: boolean, url, title, content_type, text: string, snapshot_ref: string, sha256: string}`——**快照契约（引用可核验的地基；裁决5 三说归一）**：每次成功抓取把原始响应体规范化为 UTF-8 文本**由工具副作用落 `attempt_dir/sources/<sha256前12>.txt`**（谁写、写哪），返回 `snapshot_ref`（相对路径）与 `sha256`（响应体规范化后 SHA-256）。引用条目必须携带这两值（§3.1），citation_unit 据此核验。**图上记账**：reader 节点以 **artifact_contract** 声明 sources 目录为工件产出（不进 store——INV-2 单写者不破；进图记账，§4.3-2）；cite_check 仍以 sources 全集兜底。
- **effect_class**：`external_once`（同 §2.1 判例）。幂等：同 url 同 attempt 重投递不重抓（幂等键机制，IntentKey 泛化）。
- **抓取范围约束（任务中立性 + 安全）**：v1 限 `arxiv.org`/`www.arxiv.org` 域 + 论文内引用链域白名单（配置进包内 prompts/ 配置段，不进核心）；出网面与代理待实测（§10-6）。

### 2.3 tool · `pkg.report.pdf_extract@1`（本地 PDF 文本抽取）

- **impl_ref**：`packages/reportkit@1.0.0/tools/pdf_extract.py`。
- **绑定方式**：ingest 节点 `uses.tools` 第二成员——ingest 单节点双工具（web_fetch 按 `input.url`、pdf_extract 按 `input.local_path`，实现按在场字段选路；**工具选择是实现细节不是图分支**，任务书「URL 或本地 PDF」双形态由此承载，不新造 route 面）。
- **入参**：`{local_path: string (必填)}`。
- **出参**：与 §2.2 同形（`{ok, url:"file://"+local_path, title, text, snapshot_ref, sha256}`）——PDF 抽取产物同走快照契约，引用核验两路同构。

### 2.4 unit · `pkg.report.citation_unit@1`（引用核验器——独立判分）

- **impl_ref**：`packages/reportkit@1.0.0/units/citation_unit.py`；判分子进程调用点与指纹锚见 §5.2。
- **绑定方式**：`kind: check` 节点 `uses.unit`（cite_check，§4）——check 节点内建 `passed` 端口（提案 B :125）；bind 按 unit 类解析（`bind.rs:9`）；E9003 面由实测覆盖（§4.5-② 证类别核对面存在：unit 当 tool 用即拒——G3 v2 §⑤:115-117 已有判例）。
- **入参**（argv 契约 §5.2）：`[task.json, report.json, sources_dir]`——task.json=论文定位+断言参数（rubric 阈值等）；report.json=报告工件正本；sources_dir=快照目录。
- **出参**（stdout JSON，判定值唯一来源）：`{passed: boolean, checks: {citations_total, marker_align, quote_hit, sha_match, snapshot_present}, failures: [string]}`。
- **断言集（全机器可判，零 LLM）**：
  1. `marker_align`：正文 `body_md` 中每个 `[n]` 标记在 `citations[]` 有同 n 条目，且 citations 每个 n 恰被一个标记引用（双向对齐）；
  2. `quote_hit`：每条 citation 的 `quote` 是其 `snapshot_ref` 快照文本的**子串**（规范化空白后逐字节比对）；
  3. `sha_match`：快照文件重算 SHA-256 == citation.`snapshot_sha256`；
  4. `snapshot_present`：全部 `snapshot_ref` 文件在场（缺件=fail，不虚列——承 swev 判分三件套「只记在盘文件，早期失败臂缺件不虚列」纪律，`af-execline/src/suite/swev_unit.rs:277-285`）；
  5. `citations_total >= 3`（下限入 task.json 参数，不在核心）。
- **effect_class**：unit 类无 effect_class 字段（类别×字段正交，`components.rs:340-346` 非 tool/model_route 不得携带——装载即拒）。

### 2.5 unit · `pkg.report.rubric_unit@1`（结构 rubric 验证器——独立判分）

- **impl_ref**：`packages/reportkit@1.0.0/units/rubric_unit.py`。
- **绑定方式**：第二 check 节点 `uses.unit`（rubric_check，§4）——与 cite_check 串联构成**双验证器**（ADR-006:11「rubric/引用双验证器」）。
- **入参**：`[task.json, report.json]`。
- **出参**：`{passed: boolean, rubric: [{id, ok}], failures: [string]}`。
