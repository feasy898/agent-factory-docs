### 1. 逃逸舱占比（15 稿计划 escape 记账统计）

- **定义**：对齐 15 稿（ReAct/Reflexion/Voyager/SWE-agent/MemGPT/CAMEL/

  `python3 -c "import json,glob,collections;k=collections.Counter();[k.update(v['body'].get('escapes',{}).values()) for v in map(json.load,glob.glob('crates/af-compiler/testdata/golden/*.ir.json'))];print(...)"`（完整脚本见下节）。

  - 覆盖率 **15/15 = 100%**（无一稿零逃逸舱；每稿至少 2 条，最高 LangGraph 11 条）；
  - 密度 **97 条 / 15 稿 = 6.47 条/稿**；

- **解读**：逃逸舱是零语法代价的表达出口，其覆盖率高说明 DSL 表达力缺口被

脚本 A（逃逸舱统计，golden 侧）：

```python
import json, glob, collections
drafts = ["ADAS","AFlow","Agensh-DeLM","AutoGen-Team-JSON","CAMEL","CrewAI-YAML",
          "GPTSwarm","LangGraph-StateGraph","MemGPT","MetaGPT","Multi-Agent-Debate",
          "ReAct","Reflexion","SWE-agent","Voyager"]
kinds = collections.Counter(); total = 0; covered = 0
for d in drafts:
    e = json.load(open(f"crates/af-compiler/testdata/golden/{d}.ir.json"))["body"].get("escapes", {})
    if e: covered += 1
    total += len(e)
    for spec in e.values(): kinds[spec.get("kind", "(未分类)")] += 1
print(f"覆盖率 {covered}/15，共 {total} 条，稿均 {total/15:.2f}")
for k, v in kinds.most_common(): print(f"  {k}: {v}")
```
