### 1.2 证明：`proofs/verus/route_norm.rs`（251 行，含注释）

- **侵入度：0 行 af-dsl 源码改动**（`git status`：仅新增 untracked `proofs/`；crates/ 全部 M 文件为并行任务遗留，非本任务）。注解全部住在独立目录——按任务包纪律执行。
- **路线（镜像证明，如实声明）**：Verus 自带 rustc fork 无法编译 af-dsl crate 本体（serde/serde_yaml 依赖树 + `String`/`format!` 不在其支持面），故对 `normalize` 的**算法核心**做保结构镜像后证明。抽象层（语义保距化简）：
  - `when_i`（CEL 串）→ 任意赋值 `val[i]`：互斥/覆盖是「对任意 when 真值赋值成立的命题逻辑事实」，与 CEL 语法无关，抽象不失真；
  - `goto` → usize（exit=usize::MAX 哨兵）；
  - guard 串重构 → 结构等价谓词。
- **三性质与证明形态**：
  1. **分支互斥（T1）** `lemma_mutual_exclusion`：i<j 时 guard_i ∧ guard_j 不可满足（前缀排除构造，归纳于前缀真值）；
  2. **default 覆盖（T2，恰一分支）** `lemma_first_true_or_none`（对前缀长递归归纳：proof fn 禁 while）+ `lemma_exactly_one_branch`：任一赋值下规则分支与 default **恰一个**成立（存在性 + 两两互斥 + 规则↔default 互斥三联）；
  3. **输出确定序（T3）** `norm_edges`（route.rs:172-184 边构造循环的 exec 镜像）：后条件证明边集**长度保持、逐位 targets[q]、严格升序**（BTreeSet 迭代序=升序的镜像，不变式在 targets 层维护后于出口链接）。
- **内核裁决（实跑输出，全文存 `proofs/verus/verus-route-norm.log`）**：

```
verification results:: 12 verified, 0 errors    （单次验证 0.6s；ram: tmpfs 内完成）
```

- **Verus 人体工学实况（供 FV-1 决策）**：语义/证明概念清晰，但本 PoC 经历了 7 轮迭代才全绿，全部卡点属工具微观语法/触发词问题：`assert forall … by {}` 的 `implies` vs `==>` 前件假设差异、proof fn 禁 while（须改结构递归）、exec 循环必须显式 `decreases`、SMT 触发词需手工提示（`ascending_hint`）、usize 计数器/int spec 的分域。**结论：可用的甜点区是「纯函数 + 序数逻辑」，代价在中低两位数行的语义实体约半天到一天首证。**
- **镜像漂移风险与对账**：镜像非实现本体。缓解：①镜像逐函数锚定 route.rs 行号（注释内）；②Kani 镜像穷尽（§2）对同算法独立交叉；③建议 FV-1 加一个「镜像↔实现」对账单测（diff 关键分支结构，约 0.5 天）。

### 2.3 ❌ 硬阻断（两个，均有探针实测数据，全文 `proofs/kani/src/EVIDENCE.md`）

**阻断一：kani-compiler 0.68.0 ICE——`validate` 链整体不可编译。**
直接构造最小 `Document` 调 `af_dsl::validate` → `internal compiler error: kani-compiler/src/intrinsics.rs:243:17: assertion failed: matches!(output.kind(), RigidTy::Int(I32))`；**空文档（0 节点）同样炸** ⇒ 与 harness 内容无关，在 validate 的静态可达链上（cel-interpreter→chrono 的某 intrinsic 实例化；`envelope::check` 路径不经过该链、可编译）。推论：**INV-2（E2311/E2312/E2211）与 golden 正控制的 Kani 验证在 0.68.0 下无法进行**。16 例写者穷尽 / 2 例 map 共写 / 2 例 carried / 4 例信封 / sample1 正控制共 **8 个 harness 已完整写好**，存 `src/pending.rs`（feature `blocked-harnesses` 门控，默认不编入以免拖死默认集），ICE 修复后即启用。
版本对照：Kani 0.66.0 下载在 20:10-20:25 窗口因代理 SSL 失败（curl exit 35，多次重试+退避）未成——对照未跑，如实登记。

**阻断二：CBMC 运行时爆炸——真实 `route::normalize` 与 serde_yaml::Value 路径不可用。**
- 真实 normalize（BTreeSet/BTreeMap + `format!` 守卫串）：**纯具体单用例**（无任何符号值）>5 分钟未完；4 用例符号版 >7 分钟未完。
- serde_yaml::Value：**仅构造一个 Mapping 插一个键、不跑任何 af-dsl 代码** >4 分钟未完（IndexMap/hashbrown 在 CBMC 堆模型下病态）——这就是信封 harness（编译通过）也无法收敛的原因，也是 INV-2 走 `load_str`（YAML 全解析）路线判死刑的原因。
- 对照组：同算法 Vec/整数镜像 27 用例 0.196s——瓶颈确证为数据结构/串机器，非 Kani 本身。

### 2.4 FV-0.2 判定

按任务包预授权的降级路径执行：normalize 由「Kani 有界穷尽」**以镜像形态补位**（且额外覆盖了 Verus 未证的 E 码判定逻辑）；INV-2/信封 harness **写而未跑**（ICE/病态），阻断证据可复查——这是「工具不适配是合法结论，如实记录原因」的执行，未硬凑。
