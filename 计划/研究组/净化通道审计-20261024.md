## 4. 对"净化锚 79.2%"的修正意见

净化 19/24 = 79.2% 目前**不可作为无泄漏能力锚点**：

1. **改判**：`pytest-dev__pytest-7205` 官方线败→净化线过的翻转正是暗道产物（解法 byte-identical 自宿主可达的 pytest 6.0.0 源），应改判无效或单列"暗道翻转"类。仅此一项锚值降至 **75.0%（18/24）**。
2. **加星※（保留过、标注解非自主）**：`pylint-4551`（补丁=pr4551 逐字移植）、`sphinx-7462`（自述移植宿主 3.1.0 wheel）、`pylint-7277`（补丁与宿主 2.15.0 树逐字一致）。这三题 judge 在正规评测环境判过、奖励真实性不受影响，但**能力归因无效**。
3. **加小星†（依赖层/来源未定）**：sympy-13877、pytest-8399、pylint-6528、django-11066、xarray-4075、sklearn-10297、sklearn-11578、seaborn-3187——解法大概率自主，但验证环境被宿主未来依赖污染（pandas 3.0 / numpy 2.5 / scipy 1.18 / asgiref 3.12），自验置信度失真。
4. **口径建议**：报告锚值时三档并行——名义锚 79.2%；修正锚 **75.0%**（7205 改判后）；可归因下限 **29.2%**（仅 7 干净题全部通过/24）。与"干净"线 87.5%、afG2 62.5% 对比时，净化线的真实增益区间应为 [29.2%, 75.0%]，79.2% 高估了 4–50 个百分点。
5. **净化协议补丁（防复发）**：①agent 运行环境屏蔽宿主双 python 的系统+用户 site-packages 及 /usr/local 解释器；②`repos/` 克隆 refs 截断至各题 base commit 之前（或移出宿主可读路径）；③`tmp-future-quarantine/` 移出宿主或加权限隔离（现状：未来版本库+PR 源树与 agent 同机可读，10-23 当天 16 点生成的工件 20 点就被 4551 题"located"）；④净化判定增加宿主路径接触审计钩子（对转录 grep `/usr/local/lib|\.local/lib|tmp-future-quarantine|repos/`）。
