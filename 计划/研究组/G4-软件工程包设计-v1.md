### 3.2 提示词策略挂载点

**问题**：v0.1 DSL 的提示词经 `context.sections[].template_ref`（如 `pkg.sweagent.aci_system@1`）引用，但 template_ref **不在 uses.\* 绑定面**、不进 L4 绑定对照（G3 §⑥-4 明文「context 组件注册面是后续议题」）——编译器只记账字符串（INV-1 仅查 template_ref 非空，`inv1.rs:193-203`）。

**v1 方案（零核心改动）**：提示词 = 包内**技能库资产**（ADR-006 裁决 2 四类资源之「技能库」），不进 components.json 六类（`components.rs:41-50` 类别面零扩）、不进 uses 声明面：

1. **解析约定**（装订器 planbind 实现；**裁决10：两包唯一机制、解析器一套**）：`template_ref = pkg.<包>.<名>[@<版本>]` → 读 `<包根>/<包>/prompts/<名>.md`；`vars` 字面量替换（承 af-harness `ContextTemplate` 槽位语义，落地契约 §2.1）；版本段为**可选语法**（与 uses.* 一致）；版本若给出则与 `MANIFEST.sha256` 清单版本核对。报告包改用同机制（模板文件落 `reportkit/prompts/`，报告包 §2.9）。
2. **漂移防护**：装载时逐文件 sha256 与 `MANIFEST.sha256` 核对，不符拒绝启动（EX4xxx；同 E9004 的拒绝式纪律）。模板摘要是**包级摘要面**（不并入 registry_digest——后者只盖组件声明集，`components.rs:270-283`）。
3. **载荷迁移纪律**：`swev_system.md`/`swev_instance_protocol.md` 与 Rust 常量字节一致迁出（测量语义载荷一个字节不动——`swev.rs:6-8` 纪律原文）；`SwevUnitSpec.system_prompt/instance_protocol` 从 `&'static str` 改为装载包资产（`swev_unit.rs:57-59` 字段面改动，施工批）。判据：迁移文件 sha256 == 现常量 UTF-8 字节的 sha256【待实测：施工批核对脚本】。
