# 决策摘要：Agent 可观测与持续改进策略（一页版）

> 完整依据见《agent可观测与持续改进-调研结论.md》（8 领域 80 条目调研、双评委逐条核实、统计功效复算）。
> 本页只保留决策所需信息。**所有策略的实际效果均未实测，以下全是待验证假设。**

## 一句话结论

8 条候选策略没有一条达到"直接采用"，也无一被证伪：**7 条值得并行测试、1 条（S5）建议降级**。但最先要做的不是任何完整策略，而是两件近乎零成本的"地基件"——本厂判分侧已出现过读数偏移大于多数策略预期效应的污染（fix2 原口径 ±13.3pp 被重判定为假象），**判分与可比性不牢，一切 A/B 结论都不可信**。

## 需要你拍板的 4 件事

| # | 决策 | 推荐 |
|---|---|---|
| D1 | 是否先落地两个地基件（合计数人日、近零机时）：①"未判定"合法出口+判分链逐字节重判抽检；②结果行补配置指纹字段+不可比即作废规则 | **立即做**。这是其余一切测试可信的前提 |
| D2 | 第一个实测策略选 S2（经验沉淀），样本量三选一 | **选①：120 题×7 次重复，共 1680 runs，满负荷约 1.4 天**（可判 4.8pp 效应）；想省 30% 算力则选②（×5 次重复，1200 runs，但判定门槛须诚实抬到 6pp） |
| D3 | S3（自动优化提示词）与 S2 同题集互斥，如何排 | **串行**：S2 出结论后跑 S3；两者共用同一"不注入"基线臂，省 1/3 算力 |
| D4 | S5（隐式反馈）两评委分歧（降级 vs 先测） | **降级，但先花半天跑 P0 前置检查**：统计隐式信号 eligible 占比，<10% 即维持降级（当前大概率触发，因为信号源还没埋点） |

## 8 条策略一览

| 策略 | 一句话机制 | 承诺的价值（可证伪形式） | 成本量级 | 结论 |
|---|---|---|---|---|
| **S2 经验沉淀** | 把成功/失败轨迹蒸馏成带 helpful/harmful 计数的 playbook，注入同类任务 | 通过率 +≥5pp 且 token 增幅 ≤15%，坏条目按计数淘汰不回退 | 1200–1680 runs（1–3.5 天） | test-first，**第一个测** |
| **S3 自动优化+改进门** | 用失败轨迹反思式生成提示词变体，严格改进门逐样本把关防改坏 | 加门版无逐样本退化、留出通过率显著超人工基线 | 600–1000 次执行 | test-first，排在 S2 后 |
| **S4 评审门禁** | LLM 评委先过资格门（与人标一致、位置稳定）才能给 A/B 判分，判不了就明说"未判定" | 门禁能翻转历史错误结论或制造"未判定"，而非橡皮章 | 子集近零；完整版需 300–500 条人标 | test-first，**子集属地基件** |
| **S6 灰度门禁** | 挑战者须全部指标不越界+配置指纹一致才可晋级，否则记"不可比" | 劣化漏放率 ≤5%、不可比误判=0、假阳性 ≤2% | 离线验证近零；生产灰度暂不具备流量 | test-first，**纪律子集属地基件** |
| **S7 滚动回归任务集** | 从生产流量持续合成回归任务（SWE-smith 式），防基准饱和与污染 | 4 周窗口对新增缺陷复现覆盖率 ≥80% | 需缺陷上报 ≥24 条/周（当前没有） | 暂缓：前提未备 |
| **S8 运行时重试** | 失败后定位关键错误步、从该状态局部重试，而非整轮重来 | 挽回成功数 ≥ 整轮重来的 2 倍，额外 token ≤30% | 先离线量定位命中率（数人日） | test-first，排第 4 位 |
| **S5 隐式反馈评审** | 用用户中断/拒绝/采纳信号把人工评审预算集中到高信息样本 | 同等覆盖所需人审样本量减半，AUC ≥0.7 | 需 300–500 条双人盲标 | **降级**（先跑 P0 检查） |
| **S1 反事实回放归因** | 对失败轨迹做故障注入+回滚重放，自动定位"哪个环节错" | step 定位命中率比 LLM 直判高 ≥15pp | 最大工程量在重放 harness；金标未解决 | 暂缓：排最后 |

## 建议的启动顺序

1. **地基件**（数人日，近零机时）→ 2. **S2 组级 A/B**（1–3.5 天）→ 3. **S3 GEPA 式试跑** → 4. **S6 完整门禁离线验证 + S8 定位命中率离线测量**（都不花大算力）→ 5. **S7 / S5 / S1 视前提成熟再启**。

## 四问的通用答案（所有策略共享的底座）

- **观测什么**：结果行 + 判分器分级连续量（不只二值通过率）+ 逐轮 transcript 与停止原因 + 每行身份指纹（配置/判分器/题集的哈希，缺一即不可归因）。
- **trace 怎么用**：同题配对切片、逐字节重判复核、失败轨迹喂归因/反思，而非只做报表。
- **提案怎么形成**：结构化条目（如 playbook 一条一计数），每条带预登记的判定门槛与证伪条件。
- **怎么应用**：版本冻结 → 门禁（防改坏）→ 灰度晋级 → 可回滚；"未判定"≠"无效"，禁止事后挑数据。

## 三个必须记住的限定

1. 两位评委分数量纲未校准（序相关 ρ≈0），任何"平均分排名"只是展示顺序，不是质量排序。
2. 每条策略的效应量都未实测；判定规则是预登记的证伪条件，不是预期结果。
3. 共用判分链是横向风险：判分口径一旦变更，所有历史结论须全员重判并公告。
