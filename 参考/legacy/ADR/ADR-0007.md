## 3. 后果

**影响**

1. `paused_for_human` 默认值 = `false`：VERIFYING 类卡自动流入派发，人不是默认环节。
2. `paused_for_human=true` 的唯一语义 = 「这张卡在等人，别自动派」。典型触发场景：
   pm-loop 每 5 分钟扫 `opch.tasks`，CREATED 且停滞超阈值即自动派；某些「停滞」其实是在等 owner
   决策（如「需要确认用哪个 API 方案」），不挂牌就会被误派给 dev agent → agent 瞎猜方案 → 跑错 → 再来一遍
   —— `archive/2026-10-10-baofinalstate/交接-主会话-2026-10-10.md §6 场景说明段`
3. 停滞窗维持 **24h**（`wake-policy.yaml` 的 `stall_after_hours`），不是工单字面的 30 分钟
   —— 拍板清单 `:172`（30min 会致每 5 分钟唤醒风暴）。
4. verify-agent 的落位是 **agentscope 框架内按需 spawn 的子代理**，不是新编排面 —— 与
   ADR-0001（A5）、ADR-0004（协作优先 agentscope）同批。

**落地实况（文档记载）**
