## 3. 后果

**影响**

1. 凡文档 / 指令中出现「GPU 机器」，一律解释为 **anolis-gpu-01**（`100.64.0.7`，SSH 走
   `root@100.64.0.7`；本机 `~/.ssh/config` 为空、主机名 `anolis` 不可解析，见
   `产出/实施-B-qwenpaw-retire-2026-10-10.md` §1.1）。
2. 本机 `PanDeveopComp` 承担 harness / 观测面，**不承担 GPU 角色**。v1 文档实测记录：
   anolis 侧 `nvidia-smi` = Tesla V100S-PCIE-32GB ×2（各 32768 MiB）
   —— `产出/agent系统建设-v1-2026-10-10.md:29`（§1.2 表 GPU 机器行）。

**本会话实跑复验（只读）**

```
$ ssh -o BatchMode=yes root@100.64.0.7 'hostname'
anolis-gpu-01
```
